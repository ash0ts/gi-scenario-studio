# Data and model governance

## Readiness and attribution

Every model and data asset carries a readiness level, source, license, checksum,
and modification record. A project may reference private assets without copying
them into support bundles or public benchmarks.

## Network access

Existing-model workflows perform no network access. Concept-model users must
approve each provider request after seeing its dataset, vintage, resolution,
license, and intended model influence. Provider responses are content-addressed
and can be reused offline.

## Benchmark inclusion

An asset is bundled only when redistribution is explicitly permitted. A paper's
open-access license does not automatically license a repository's model files.
Public visibility is not permission.

## Diagnostics

Diagnostics are local and redacted by default. The user selects whether a
support bundle includes model files, coordinates, project names, or source data.
