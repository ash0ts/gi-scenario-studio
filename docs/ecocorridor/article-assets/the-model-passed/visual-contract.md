# Why I Built EcoCorridor: figure contract

These figures explain retained synthetic evidence and an historical agent campaign.
They introduce no new experiment. The manifest names the four current figures;
the earlier decision-card and hypothesis-bar files are historical assets only.

## Audience and source boundary

The audience is a technically curious builder meeting connectivity modeling for
the first time. Each visual answers one question encountered while following a
portfolio or checking the agent experiment. No figure establishes ecological
validity, animal behavior, collision reduction, practitioner usefulness, or
approval. There is no animation: comparison and mandatory release checks are
clearer as inspectable stills.

## Composition and semantics

The three generated figures use a six-inch portrait canvas, stacked comparisons,
plain titles, and visible limitations. Main wording is 13.5–18 pt; supporting
scale ticks are 12 pt. Color is local to each figure: cyan represents modeled
current or the agent arm, graphite the comparison arm or structure, amber the
review mask/caveats, and berry failed-release exits or the promotion gate.
Labels, position, and arrows carry the same meaning without color.

The workflow groups exact Weave readback, authorization recheck, validation,
and local rendering as mandatory release checks. This avoids drawing a false
timing claim: the subprocess reads back the trace before worker-side rendering.
Every shown failed gate terminates without a saved draft.

The screenshot remains unaltered. At narrow width its long IDs require opening
the full image; the article's adjacent text and linked source record must
carry the reconstructable result without requiring the reader to decipher pixels.

## Validation

- Renderer checks candidate identity, complete 12-scenario ensemble, `review`
  disposition, matching raster dimensions, 48 valid mask cells, and the masked
  current calculation against the projection at absolute tolerance `1e-9`.
- Manifest retains exact source and output SHA-256 hashes, numeric precision,
  captions, alternatives, and forbidden implications.
- Native PNGs and browser renders at 700 px and 375 px were visually inspected.
  No figure or caption overflowed. Browser QA used only in-memory synthetic
  images with non-data network requests blocked.
- Historical token totals are explicitly labelled as the four teaching-portfolio
  cases, not all 14 cases, 42 campaign records, or 22 provider conversations.

Read-only verification screenshots are in the ignored
`test-results/article-figure-qa/` directory. Live Report column and mobile
verification is performed separately during publication.
