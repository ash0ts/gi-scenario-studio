# EcoCorridor search-gate artifacts

This directory contains only self-authored CC0 synthetic algorithm-release
fixtures derived from the earlier complete Ridgeway v1.0 direct Circuitscape
evidence index:

- one immutable table for each reviewed Ridgeway resistance hypothesis;
- `manifest.json`, binding those tables to the direct evidence-index digest;
- `release-gate.json`, the deterministic random/Sobol/Sobol+ExtraTrees campaign.

These artifacts benchmark candidate ordering only. They are not ecological
decision evidence, animal-movement predictions, crossing-use predictions,
collision-reduction estimates, population models, approved corridors, or
design-ready recommendations.

Their source archive is now `SUPERSEDED_NON_RELEASE` for the active replay
contract. These tables remain immutable benchmark-only material; they cannot
authenticate current model results or enable production adaptive search.
`historical-provenance.json` pins that archive, its bundle and evidence indexes,
the unchanged campaign and resource sidecar, and passive copies of the exact
generator-source bytes declared by the sidecar. Those source copies are a
digest-matched recovery, not an authenticated execution attestation.

Do not hand-author outcome rows. Regenerate them with
`ecocorridor-benchmark derive-ridgeway` only after the complete pinned direct
study succeeds. See `docs/ecocorridor/search-benchmark.md` for the exact
commands and fail-closed production gate.

The current campaign fails the scientific thresholds and has no immutable W&B
artifact pin. Adaptive ML is therefore disabled; scrambled Sobol remains the
production search method.
