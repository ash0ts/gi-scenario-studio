# Ridgeway Crossing fixture

Ridgeway is a deterministic, self-authored CC0 input fixture. The source model
is generated by `ecocorridor_core.ridgeway.build_ridgeway_fixture` and contains
four synthetic cores, one highway, three anonymous guild scenarios, four
resistance hypotheses, eight intervention sites, and 128 fixed portfolios.

The repository retains two deliberately distinct packages:

- `ridgeway-direct-evidence-4858c0a48841.tar.gz` is checksum-pinned historical
  v1.0 benchmark material. It predates the current model identity and v1.1
  semantic/resource evidence contract and is never loaded as the active replay.
- `ridgeway-direct-evidence-f93ad36f3cdc.tar.gz` is the locally verified current
  package. It contains 1,536 accepted matrix jobs and 60 accepted current-map
  jobs, 1,596 whole-process-tree exit confirmations, one resource observation
  per job, and the complete current v1.2 UI projection. Its archive SHA-256 is
  `f93ad36f3cdc36b702a3cb612cbd52c306f5b231f353982de0adaee6174e5e24`.

The active desktop and no-login replay now use the current, manifest-bound
projection. This is local semantic evidence, not the protected GitHub Actions
producer attestation required for Pages or a signed release.

The Python toy circuit solver is not an alternate generator for Ridgeway. It is
restricted to hand-calculated unit tests and cannot produce a release evidence
contract.

## Materialize inputs only

`materialize_inputs.py` deterministically writes the four resistance rasters,
three focal rasters, twelve normalized included-pair sources, and the fixed
128-portfolio study plan as ESRI ASCII/JSON inputs. It deliberately does not run
Circuitscape or write outcome values:

```text
PYTHONPATH=python .venv/bin/python \
  benchmarks/ecocorridor/ridgeway/materialize_inputs.py /path/to/empty/output
```

## Run the direct study

The resumable runner uses the committed Julia project and requires the pinned
Julia 1.12.6 runtime, Circuitscape 5.17.1 depot, and an external evidence
directory. The study is first written outside Git; after every required direct
job and teaching-role check succeeds, `scripts/package_ridgeway_evidence.py`
validates and packages the accepted artifacts for local replay verification:

```text
PYTHONPATH=python .venv/bin/python \
  benchmarks/ecocorridor/ridgeway/run_direct_study.py \
  --output /path/outside/repository/ridgeway-evidence \
  --julia .toolchains/julia-1.12.6/bin/julia \
  --project julia/EcoCorridorEngine \
  --depot .julia-depot \
  --workers 4
```

Each direct job uses an isolated attempt directory and writes an atomic,
hash-verified completion record. Re-running the same command verifies and reuses
completed jobs. A partial run returns `INCOMPLETE` and cannot publish a replay.
The direct runner never writes release resources into the repository; publishing
is a separate, independent verification step below.

## Package verified evidence

The packager accepts only a complete direct-study directory. It verifies job
coverage, QA, artifact hashes, model and engine identities, then writes the
deterministic archive, direct-evidence manifest, and identical benchmark and
desktop projections:

```text
PYTHONPATH=python .venv/bin/python scripts/package_ridgeway_evidence.py \
  --evidence-root /path/outside/repository/ridgeway-evidence \
  --publish-directory benchmarks/ecocorridor/ridgeway \
  --desktop-fixture apps/ecocorridor-desktop/src/data/ridgewayFixture.json
```

Release verification requires all of the following:

- Exact engine/runtime/component hashes in the evidence manifest.
- Accepted QA and complete required pair metrics for every job.
- Teaching portfolios selected from observed evidence, never pre-authored IDs.
- A UI projection whose manifest hash matches the direct-evidence manifest.
- An archive whose exact member set, byte sizes, and SHA-256 values match its
  internal `bundle-index.json`.
- One independently validated resource observation for each of the 1,596 jobs,
  plus an exact aggregate shared by the evidence manifest, bundle index, and UI
  projection.

The authored budget, scenario labels and IDs remain fixture metadata. All
displayed connectivity outcomes, direct-run identities, diagnostic current-map
summaries, and teaching selections in the verified replay are derived from the
retained Circuitscape evidence. The historical archive remains benchmark-only.
Pages and release staging still fail closed until the independent protected
producer chain verifies this committed reference package on the same commit.

## Protected producer gate

Local packaging is not execution attestation. After a current package is
committed and the same commit passes the complete Eco CI (including the
fail-closed Julia vulnerability job), an authorized reviewer must manually run
`EcoCorridor protected Ridgeway direct evidence` on `main` and provide that CI
run ID. The workflow uses a clean runner directory and executes all 1,596 jobs;
`--job-limit`, cached evidence inputs, and precomputed outcome imports are not
part of this path.

The producer artifact retains its independently resolvable GitHub Actions run
identity, the complete regenerated package, and a tolerance-based differential.
That differential compares every focal-pair value from all 1,536 matrix jobs
and 60 map jobs plus every cell in all 60 retained current rasters. Runtime,
memory, and energy observations remain separately reportable and are not
expected to be byte-identical across machines. Pages must be manually
dispatched with the exact successful producer run ID; signed release resolves
the same immutable artifact independently. An internally consistent archive
without this protected producer chain cannot be deployed or released.
